# runescape-dragonwilds-mods

Small, unofficial mods for **RuneScape: Dragonwilds**. Each mod lives in its own folder with its own README, install steps and release zip.

| Mod | What it does |
|---|---|
| [Large Bucket Fast Fertilize](large-bucket-fast-fertilize/) | Large Compost Bucket discharges 25 fertilizer per tick (two ticks per 50-fertilizer plot). |

Fan-made and not affiliated with or endorsed by Jagex. Use at your own risk.
